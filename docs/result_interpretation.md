# Result interpretation

Synthetic accuracy compares a candidate with a planted known target. Bootstrap stability measures
sensitivity to resampling the measured dataset; it is not accuracy. Real P12 accuracy can only be
calculated by the Tracker-confirmed blinded evaluation procedure. Prefix analysis is chronological only
for shot-level data; multinomial subsets of counts are explicitly labeled resampled analysis.

Parsing, round-tripping, structural validation, small-fixture semantics, backend predicates, and real
hardware behavior are distinct evidence layers. Passing an earlier layer does not imply a later one.
