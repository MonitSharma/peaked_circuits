# Result interpretation

Synthetic accuracy compares a candidate with a planted known target. Bootstrap stability measures
sensitivity to resampling the measured dataset; it is not accuracy. Real P12 accuracy can only be
calculated by the Tracker-confirmed blinded evaluation procedure. Prefix analysis is chronological only
for shot-level data; multinomial subsets of counts are explicitly labeled resampled analysis.

Parsing, round-tripping, structural validation, small-fixture semantics, backend predicates, and real
hardware behavior are distinct evidence layers. Passing an earlier layer does not imply a later one.

Provider data are not analysis-ready until normalization succeeds. Ambiguous records never enter
recovery. Mapping-circuit agreement validates ordering, not P12 accuracy; an `unsupported` cost report
is not a cost estimate.

QIR structural validation proves that the exported module parses, verifies, declares 98 static
qubits/results, and contains the locally expected logical measurement pairs. A successful
`Helios-1SC` result would add provider-syntax evidence only. Neither determines the order in which a
future emulator result is displayed, so `provider_result_position` remains unresolved until real
`Helios-1E` mapping results are imported in a later milestone.
